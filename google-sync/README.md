# Sincronização Google — Comida de Vó

A sincronização usa uma conta Google da empresa como conta central. Os aplicativos não armazenam a senha do Google.

## Como funciona

1. O responsável autoriza a conta Google da Comida de Vó uma única vez.
2. O app usa essa autorização para salvar/ler os dados compartilhados.
3. No segundo celular, a mesma conta Google pode ser autorizada.
4. Depois o mesmo acesso pode ser usado no computador.

## Importante

A autorização Google precisa ser feita pelo próprio usuário na tela oficial do Google. O aplicativo nunca deve pedir ou armazenar a senha.

Esta pasta contém a configuração/base do recurso. A publicação do backend Google e a credencial OAuth pertencem à conta Google do responsável e precisam ser criadas nessa conta antes de a sincronização real poder funcionar.
